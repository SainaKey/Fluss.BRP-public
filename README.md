# Fluss
FlussはジェネラティブVJソフトウェアの開発に特化したUnity上で動作するノードベースプログラミング環境です。

# サンプル
本サンプルを動作させるためには、[DOTween](https://assetstore.unity.com/packages/tools/animation/dotween-hotween-v2-27676?locale=ja-JP&srsltid=AfmBOoqRDXFiSdWJm4nqumBRSKJpUU664LfqPpzV7tBhohrIzZS6VI_Y)と[AreaLit Shader](https://lox9973.booth.pm/items/3661829)が必要です。
ノードベースの機能自体はこれらのアセットが無くても動作します。
